Как открыть сайт через VS Code:

1. Установите VS Code.
2. Установите PHP, XAMPP или OpenServer.
3. Откройте папку legal_site в VS Code.
4. Запустите локальный сервер:
   php -S localhost:8000
5. Откройте в браузере:
   http://localhost:8000

Форма заявки сохраняет обращения в файл leads.txt рядом с index.php.
Телефон, email и название компании можно заменить в index.php.
